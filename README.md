# Focus – Menu Bar Timer

Public support and privacy pages for the Focus macOS app, served with GitHub Pages:

- Support: https://kennethegholm.github.io/focus-app/
- Privacy policy: https://kennethegholm.github.io/focus-app/privacy/
- Dansk: https://kennethegholm.github.io/focus-app/da/

Install: [App Store](https://apps.apple.com/app/id6833000003), or with Homebrew — `brew tap kennethegholm/focus && brew trust kennethegholm/focus && brew install --cask focus-menu-bar-timer`. Downloads are under [Releases](https://github.com/KennethEgholm/focus-app/releases).

Questions or problems: [open an issue](https://github.com/KennethEgholm/focus-app/issues).
